系列（資產層）

系列＝影片入庫的分群單位（如同一批來源/術式），與標註專案互相獨立。 系列 ID 為系統產生的四碼英文（不可改），影片編號依系列自動配號（如 ABCD_0001）。 名稱／機構／手術類別隨時可改，ID 與影片編號不受影響。

入庫新影片（病人資料夾 → 合併 → 去識別化 → 標準化）

每個病人資料夾（內含一段或多段錄影檔）會被處理成一支標準化影片： 依檔名排序合併（順序由你確認）→ 偵測體外（out-of-body）畫面 → 人工核可切除段（QC 關卡） → 切除並轉成 720p/25fps → 去音軌與 metadata → 依系列自動配號入庫。 原始檔全程唯讀；入庫成功後原始資料夾移至 archived/ 保存（不刪除）。
（系列必選；專案可選）
把病人資料夾放到伺服器的 data/raw_videos/_incoming/（一夾一病人）後按重新掃描。

確認合併順序 —

下列檔案將由上而下依序合併成一支影片。預設為檔名排序， 可拖曳調整順序；確認前請比對錄影段落先後（順序錯了合併結果無法回復）。

QC：核可切除段 —

以下是自動偵測到的體外（out-of-body）段落，將從影片中切除（邊界已自動外擴 ±1 秒）。 請抽查縮圖：可微調起訖秒數、刪除誤判段、或新增漏抓段。 核可後才會開始切除與轉檔；誤留體外畫面＝隱私事故，寧可多切。 切除段為模型依體外機率門檻 0.7 建議；標「存疑」＝模型不太確定該段是否真為體外，請優先檢查這些段的縮圖。
