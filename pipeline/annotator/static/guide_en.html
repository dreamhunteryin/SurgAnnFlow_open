SurgAnnFlow Annotator User Manual

This is the operating guide for the surgical-video annotation platform. You need no front-end or server background—just follow each section step by step. The interface follows a Roboflow-style design: pick a tool first, draw the shape first, then choose the class afterward. Temporal segment annotations (on the timeline) and spatial region annotations (on the frame) are both done in the same web page. Videos are organized into libraries by project, and once annotated you can export a dataset directly from the web page.

1Platform overview (project → video → annotation → export)

The whole platform workflow is just four steps:

  1. Project: first create or select a project. Each project has its own class list (taxonomy) and its own videos.
  2. Video: "ingest" a source video into the project—the system standardizes it to 25fps and registers it.
  3. Annotation: click a video card to enter the annotation page, then use the tools to draw temporal segments and spatial shapes.
  4. Export: click "Download dataset" on the project page for one-click export, or have an administrator convert it into a training format with the surgann command.

Annotation itself comes in two kinds, both done in the same interface:

  • Temporal annotation: draw "a span of time" on the timeline. For example, "from 3:20 to 5:00 is the Calot_triangle_dissection phase."
  • Spatial annotation: outline an object on the video frame. For example, "in this frame, this box is gallbladder."
A few terms explained
• Project: as in Roboflow, one project = one annotation task (e.g. "cholecystectomy phase annotation"), with its own videos and class list.
• Frame: a single picture of the video. This platform always standardizes video to a fixed 25 frames per second, so "which frame" maps to "which second" rigidly one-to-one (seconds = frame ÷ 25), which keeps annotation positions precise.
• Registry: a database file (registry/registry.db), the platform's single source of truth. Projects, videos, classes, and annotations are all stored in it; every action you take in the web page is written to it immediately—the web page is only a "workbench," while the real data asset lives in the registry.

2Video library and projects

An administrator first starts the service in the terminal (surgann annotate), then you open the URL in a browser (default):

http://127.0.0.1:8090

Landing page: project cards

What you see after opening the URL is the project list. Each project is a card showing: the project name, a type badge (temporal / spatial / mixed), the annotation group (what this project is annotating), and the video count.

  • Click a project card → enter that project's page.
  • Click "＋ Create project" → a dialog pops up; fill in three fields: project name (e.g. Cholecystectomy Phases), type (temporal = timeline only / spatial = frame only / mixed = both, default mixed), and Annotation group (a one-line description of what is being annotated, e.g. surgical phases). You can also optionally "copy classes from an existing project"—this brings all of the source project's classes (including the triplet three dropdowns) into the new project, copying only the classes, never the annotations (off by default). Click "Create" to finish.

Project page: four tabs

The project page has four tabs on the left (the title bar also shows the project code—a fixed identifier that export and the CLI use to specify the project):

TabContents
🎬 Videos The video list for this project. Each card: thumbnail, video number, series badge, status badge, length / resolution / fps, and the annotation count within this project. Click a card to enter the annotation page; the top-right also has "＋ Add video" and each card has "Remove from project" (explained below).
📥 Upload data Fast ingest of a single video file: a results table from scanning the server disk data/raw_videos/ (filename / size / video_id / status). Place the file into that directory first (the source file is read-only and is never modified), choose "ingest into series," then click "Ingest" to standardize it into a 25fps video and add it to this project. The video_id is auto-assigned by the system per series ({series ID}_{four digits}, e.g. ABCD_0004); no manual naming is needed. Transcoding large files takes a few minutes; the status shows "⏳ Ingesting…," and when done a new card automatically appears in the Videos tab. If a file is already ingested but not yet in this project, an "＋ Add to this project" button appears—one click, no re-transcoding needed. For a patient folder (multiple recording segments that need to be merged and de-identified), use the "📥 Video ingest" page instead (see below).
🏷 Classes The taxonomy management for this project: the class lists for each layer—phase / action / event / spatial—which can be added, renamed, recolored, or deleted at any time. Renaming updates existing annotations in sync; deleting a class that is already in use prompts for confirmation first (its annotations are deleted along with it). Above there is also "Import classes from another project": merges the source project's classes into this project (same-layer, same-name entries are skipped automatically; annotations are not copied).
📦 Download dataset Choose the export format (MOSaiC / COCO / YOLO / temporal / spatial) → click "Export" → when done an ⬇ Download zip link appears. The export scope = this project. See Section 12 for details.

Add a video to a project (does not copy the video)

A video only needs to be ingested once; after that any project can "reference" it—the same video can belong to multiple projects simultaneously, and each project's annotations are independent (what you annotate in project A is not visible in and not affected by project B). There are three entry points for adding a video to a project:

  • ＋ Add video (top-right of the 🎬 Videos tab): pops up the video library list, showing ingested videos not yet in this project (with series and duration); click "Add" on each one.
  • 📚 Import entire series (at the top of the same dialog): choose a series (e.g. ABCD) → click the button → all videos in that series are added at once (those already in the project are skipped automatically).
  • 📥 Upload data: for a not-yet-ingested file click "Ingest" (after transcoding it is added to this project automatically); for an already-ingested one click "＋ Add to this project."

Remove a video from a project

The "Remove from project" control at the top-right of a video card (appears on mouse-over) removes the video from this project's list; the video itself stays in the video library, and other projects are entirely unaffected. If this project already has annotations on this video, a warning appears first ("This project has N annotations on this video; removing will delete them too")—after you confirm, these annotations are deleted (other projects' annotations are untouched), so be sure to read the count carefully before confirming.

Video library and series (lower half of the Landing page)

Below the project cards on the Landing page is the video library: all ingested videos are shown in two levels by series folder— the first level lists series cards (name, series ID, video count, institution / procedure); clicking in lists that series' video cards (videos with no series go into an "Unclassified" folder; "← Back to series list" returns to the upper level). Opening a video from the video library is pure browse mode: only the player and video info, with no annotations or annotation tools shown; the right side of the page lists the "owning projects," and only by clicking "✏ Open annotation in this project" do you enter full annotation mode—annotation is always accessed through a project (the same video's annotations in different projects are independent of one another). A series is the grouping unit at video-ingest time (the asset layer, e.g. one batch of sources or one type of procedure), and is independent of annotation projects: a series manages video assets, a project manages annotation work. Series are created and managed on the "📥 Video ingest" page (name / institution / surgery category can be changed at any time; the four-character series ID is system-generated and cannot be changed), and video numbers are auto-assigned per series (e.g. ABCD_0001). Videos in the same series can all be added at once from the project page via "Import entire series."

Video ingest page (batch ingest of patient folders + de-identification)

Enter it via "📥 Video ingest" at the top-right of the Landing page. A full surgery is often split by the recorder into multiple files placed in one patient folder; this page processes the entire folder into one de-identified standardized video, in five steps:

  1. Choose a series (or create a new series at the top of the page first); you may also select "add to an annotation project when done."
  2. Provide the patient folder, via one of two entry points: select from server disk (an administrator places the folder into data/raw_videos/_incoming/, then click Rescan) or upload from browser (select the local folder directly, uploaded in 50MB chunks, resumable after a disconnect).
  3. Confirm the merge order: the system lists all files sorted by filename; you can drag to reorder before queuing them for processing (a wrong order makes the merge result unrecoverable, so compare the sequence of recorded segments; if a "⚠ mtime inconsistent" warning appears, check especially carefully).
  4. The system automatically: merges → detects out-of-body frames → stops at "Awaiting QC approval"—click "🔍 QC approval" to review the thumbnails of the suggested segments to cut out, where you can fine-tune the start/end seconds, delete false positives, or add missed segments; only after approval are they cut and transcoded. The confidence badge next to each segment: ● High confidence (green, median out-of-body probability ≥ 0.9) is mostly reliable; ▲ Uncertain (yellow, < 0.9) = the model is not very sure, so check these segments' thumbnails first for false positives. Leaving out-of-body frames in = a privacy incident, so err toward cutting more.
  5. When done the video is auto-ingested (numbered per series) and added to the selected project; the original folder is moved to archived/ for safekeeping (not deleted), and the bottom of the page shows the reclaimable space for the administrator's reference.

The processing queue runs one folder at a time and resumes automatically if the server restarts; a failed job can be "retried" or "deleted" (on delete you may choose to also clear the temporary files).

Video not showing up in the project? First confirm the video is ingested, then use any of the entry points above to add it to this project. If the file is not in the scan table under "📥 Upload data," ask the administrator to place the video into the server's data/raw_videos/ (see Section 13).
We recommend watching the video from start to finish once before you begin annotating; having a sense of the overall flow makes you more efficient.

3Entering the annotation page

  1. Landing page → click a project card.
  2. Project page "🎬 Videos" → click a video card (equivalent to opening app.html?v=ABCD_0001).
  3. After the annotation page loads, the available class list is this project's taxonomy (each project is independent).

In the annotation page's top bar:

  • 📁 Video library: return to the project page to switch videos / switch projects.
  • ☰ Menu: contains "📖 User Manual (new tab, this very page)" and "⌨ Shortcut list."
  • The middle shows the current video number and the project badge (annotations are recorded under this project).
  • The right side is the annotator selector (see below).

Choose the annotator (confirm before you start!)

The "Annotator" dropdown at the top-right determines who each subsequent annotation is credited to. Confirm it is set to you before you start annotating:

  1. Open the dropdown and select your name.
  2. Not in the list? Select "＋ Add annotator…" → enter a name (e.g. Dr. Wang) → confirm, and the system adds you to the roster and selects you automatically.
  3. Once selected, the browser remembers it and fills it in automatically next time; if someone else takes over mid-way, remember to change this first.
The same video in the same project can hold annotations from multiple annotators at once; on export, each annotation carries its annotator info, so you can later break down or compare them separately.

5Core workflow: draw first, choose class after

SurgAnnFlow uses a Roboflow-style flow—you don't have to decide the class first; draw the thing first, and only after you finish does the system ask "what is this":

  1. Pick a tool: click it in the right toolbar, or press its shortcut (B box, T segment…).
  2. Draw: draw a shape on the video (spatial); for temporal, press T to record the start, play/click the timeline to extend, and Enter to set the end (Section 6).
  3. Choose a class: once you finish, a floating class menu (class popup) pops up automatically, listing this project's classes (e.g. gallbladder, hook…). Click one, or type to search then press Enter.
  4. Done: the annotation is saved to the registry immediately (an "Annotated ×××" toast appears at the bottom-right), and this annotation is auto-selected.

Using the floating class menu

  • Search box: type to filter; ↑/↓ to move, Enter to select.
  • Add a class: type a name that doesn't exist, and "＋ Add '×××'" appears at the bottom of the list; click it (or press Enter) to add the new class to this project's taxonomy and apply it right away (see Section 10).
  • The last-used class is marked with ↩ and is highlighted by default—just press Enter to apply it, handy for annotating the same thing repeatedly.
  • The temporal menu has tabs: four tabs—phase / action / event / triplet—switch the layer first, then choose the class (see Section 6).
  • Esc: discard this drawing (the shape is not saved).

N: auto-apply the last class (accelerator for annotating the same object repeatedly)

Once turned on with N, every finished shape immediately gets the last spatial class applied, without popping up the class menu— ideal for annotating dozens of the same object type in one go. Press N again to turn it off.

  • You must have manually annotated one spatial first (so there is a "last class" to apply).
  • If the current tool is not a drawing tool when you turn it on, it auto-switches to ▭ Box.
Typical rhythm: B to pick the box tool → draw the first one → choose hook → press N → from then on every box you draw is automatically hook → press N when done to turn it off.

6Temporal annotation (time segments)

Temporal annotation draws "a span" on the timeline. There are four layers, fully independent of one another and freely overlapping:

LayerMeaningExample
phaseSurgical phasePreparation, Calot_triangle_dissection…
actionAction / verbgrasp, dissect, clip…
eventPoint or short-segment eventbleeding, CVS_achieved…
tripletAn (instrument, verb, target) triplet attached to an intervalgrasper + dissect + cystic_duct

Annotate a temporal span (annotate as you watch)

  1. Line up the start first: pause the video, or click the timeline to jump to the target frame.
  2. Press T or click the ⏱ Segment tool = start annotating; the start is the current frame. An orange "⏺ Segment annotation in progress" bar appears above the timeline, showing the current start/end and length.
  3. Extend this span's length, in either of two ways which may be mixed:
    • Play the video (Space)—the span follows wherever the playhead goes;
    • Click a spot on the timeline—the span scales to that time point automatically (clicking before the start pulls the start earlier).
  4. Press Enter or "✓ Confirm" on the orange bar = set the end, which pops up the class menu (the four tabs phase / action / event / triplet), with the last-used class highlighted by default.
  5. Press Enter again = finish with the default class directly; to change the class, click the list (or type to search + Enter).
  • "Segment" is one-shot: after each finished annotation the ⏱ button automatically returns to the inactive state; clicking the timeline when not annotating just seeks and never creates an annotation.
  • While annotating, pressing T again (or the ⏱ button) = cancel this span; Esc works too (any time before confirming).
  • The tabs remember the last layer you used, so annotating the same layer in a row needs no re-switching.
Rhythm for annotating the same class repeatedly: line up the start → T → play to the end → Enter → Enter—two presses of Enter is one annotation.

The triplet three dropdowns

After choosing a class in the triplet tab of the class menu, the selection details panel shows three dropdowns—instrument / verb / target; once all three are chosen, a surgical-action triplet is complete.

Fine-tuning and deleting

  • Double-click a segment = open the edit dialog: you can directly change the class and the start/end frame, and changing start/end makes the video jump to that frame in sync.
  • Drag an edge (must enter edit mode first): after selecting a segment, press E to enter edit mode before you can drag the segment's left/right edges—without edit mode it is pure browsing and there is no accidental drag. As you drag, the video frame follows along, so the frame tells you exactly which second / frame you've dragged to. Press E again or select another annotation to leave edit mode.
  • Very short segments (e.g. 1 frame) are draggable too: in edit mode, click its left half to drag the start, right half to drag the end.
  • Clicking any annotation on the timeline makes the video jump to that annotation's start in sync.
  • The Start / End fields in the details panel accept a frame directly; the adjacent ⌖ = set to the current frame.
  • Delete: after selecting, press Del, use "Delete" in the edit dialog, or the 🗑 in the layers panel.
"The event is only an instant" is fine too—stop on that frame, press T then Enter directly for a 1-frame annotation; for regularly spaced point events, use "sampling to generate events" (Section 9).

7Spatial annotation (on-frame regions)

Spatial annotation draws shapes on the video frame to enclose objects. Five hand-drawing tools plus one AI-assist tool:

ToolKeyHow to draw
▭ Box (bbox)BHold and drag out the diagonal.
⬠ PolygonPClick point by point; finish with Enter or a double-click (at least 3 points).
• PointOOne click completes it.
⬭ EllipseEHold and drag out the bounding box.
〰 PolylineLClick point by point; finish with Enter or a double-click (at least 2 points).
✨ Smart (SAM assist)SClick an object = positive point, hold and drag = box prompt; the AI generates a polygon preview in real time (blue dashed ghost + confidence score). Corrections are intuitive: clicking "inside" the preview ghost = automatically a negative point (subtracts the clicked area from the shape, red dot), clicking "outside" the ghost = positive point (green dot)—usually no need to hold Alt; Alt+click = force a negative point (wherever you click). You can keep adding points / redrawing the box to refine, and Ctrl+Z undoes the last point/box step by step; Enter or the "✓ Confirm" button on the floating bar = accept → choose a class to land it as a normal polygon, while Esc / changing frame / changing tool = clear and start over.
✨ Smart tool notes
• Requires the back-end SAM model service to be ready; when not ready it warns "SAM model not ready" (other tools are unaffected).
• The first click on a given frame requires a brief wait (within ~0.5 s on GPU; several seconds without GPU), and subsequent corrections on the same frame are nearly instant.
• Polygon vertex cap is 150: even at the finest slider setting, if it would exceed the cap the system automatically increases the simplification strength to converge under 150 (too many vertices makes later point-by-point editing painful).
• Precision slider (floating bar at the bottom-left of the canvas, appears under the smart tool): controls how many polygon vertices there are—"finer" means more vertices that hug the shape more tightly, "simpler" means fewer vertices that are easier to edit; the current preview's vertex count is shown live beside it. Default is "Auto" (the system tunes to a moderate vertex count); dragging the slider switches to a manual value (which is remembered and reused next time), and the "Auto" button switches back at any time. Dragging only changes the simplification level; the positive/negative points and box you've placed are all preserved.
• Once landed it is a normal polygon annotation (single frame, interpolation off): you can edit vertices, copy, delete, and export it as usual.

Finish → the class menu pops up → choose a class → save (the flow in Section 5). A crosshair appears while drawing to help you line up; Esc cancels the drawing.

Clicking beyond the image bounds is fine too—the system automatically takes the point on the image boundary nearest the mouse as the vertex (the coordinate snaps to the boundary), so drawing an edge-hugging bbox / polygon doesn't require pixel-perfect aim.

Keypoint + linear interpolation (let one box move across multiple frames)

Spatial annotations have a time span (start/end frame). You don't have to draw every frame—just adjust the shape at the key frames, and the system automatically interpolates the positions in between.

  1. Draw the shape (the first keypoint lands on the current frame).
  2. With the ⬚ Select tool select it, press E (or quickly double-click with the left button on that annotation) to enter edit mode, then play or jump to a later frame.
  3. Drag the shape body or one of the white vertex handles—this saves a new keypoint on the current frame (the annotation's time range automatically extends to cover this frame).
  4. For every frame between two keypoints, the shape position is computed automatically by linear interpolation.
Interpolation rules (the details panel has an "interpolation" toggle)
• Interpolation on: between the preceding and following keypoints, if the vertex counts match → per-coordinate linear interpolation; if the vertex counts differ (a polygon gained or lost points) → hold the previous keypoint (hold); beyond the two ends → take the nearest end's shape.
• Interpolation off: the shape is only shown on frames that have a keypoint.

After selecting a spatial annotation, the details panel lists all keypoints (◆ f123): click one to jump to that frame, or ✕ to delete that keypoint (at least one must remain). The transport's ◆◀ / ▶◆ jump to the previous / next keypoint; the spatial track on the timeline also marks keypoint positions with the ◆ diamond.

Editing shapes and vertices (after selecting, press E, or left-double-click the annotation, to enter edit mode)

  • Select first, then press E: without edit mode it is pure browsing (clicking a shape only selects it, no accidental drag); only after entering do the white vertex handles appear and become draggable. Press E again / press Esc / select another annotation to leave.
  • Move: drag the shape body—it stops at the image boundary on contact, so moving the whole shape never pushes it off-frame. Reshape: drag a white vertex handle (a bbox's four corners, an ellipse's four axis ends, or each vertex of a polygon/polyline); dragging a single vertex beyond the image still snaps to the nearest boundary point as before. Each drag = save a keypoint on the current frame.
  • Ctrl+click (polygon / polyline, in edit mode): clicking on an edge inserts a vertex; clicking on an existing vertex deletes that vertex.
  • Alt+left-drag (polygon, in edit mode): redraw a stretch of edge along the mouse path— from near an edge hold Alt and drag out the desired new contour (a pink preview line), and on release the "old edge segment closer to the path" is replaced by the path you drew. Too short a path, or a start/end too far from the edge (>40px), prompts and is not applied.
  • Quick way to enter edit mode: under the Select tool, a quick left-double-click on an annotation = select it and enter edit mode directly (same as pressing E).
  • After editing, Ctrl+Z undoes as usual (including Alt+drag redraws).

Copy / paste shapes

  • Ctrl+C: copy the currently selected shape (as positioned on the current frame).
  • Ctrl+Shift+C: copy all visible shapes on the current frame.
  • Ctrl+V: paste onto the current frame (class and position preserved, becoming a new independent annotation).
  • For batch copy after a multi-selection (Shift+left-click), see "Multi-selection and batch operations" in Section 8.

Video zoom (for small objects)

  • Ctrl+scroll: zoom the video centered on the cursor (up to 10x).
  • Scroll = vertical pan, Shift+scroll = horizontal pan—only active when zoomed in (>100%); at 100% scroll does not move the frame, and panning cannot go beyond the image edges either.
  • When zoomed in (>100%), a thin scroll bar appears on the bottom / right edge of the frame: drag the thumb or click the track to pan left/right / up/down (the range likewise stays within the image edges); it hides automatically at ≤100%.
  • Double-click in the video area to reset the zoom (no accidental reset while drawing or selecting).
Current spatial tool coverage: box / polygon / point / ellipse / polyline, plus the built-in ✨ SAM smart assist (above in this section)—enough for everyday annotation. A pixel brush mask is not available yet: when you need per-pixel segmentation, annotate with polygons (or the polygons SAM generates), which export as segmentation in COCO.

8Timeline and layers panel

Timeline (MOSaiC-style split tracks, three-level tree)

The left gutter of the bottom timeline is a three-level tree structure:

  • Level 1: the two top groups TEMPORAL / SPATIAL.
  • Level 2: under TEMPORAL, grouped by layer (PHASE / ACTION / EVENT / TRIPLET); under SPATIAL, grouped by shape type (▭ bbox, ⬠ polygon, • point, ⬭ ellipse, 〰 polyline).
  • Level 3: each annotated class gets its own track—different classes are never mixed in the same row.
  • ▸/▾ collapse: the first two levels' headers have a collapse/expand button at their left edge (clicking the left half of the header row also works)—collapsing only folds the tracks below to shorten the view, it is not hiding the annotations (they still show on the video and in the layers panel; the 👁 eye button behavior is unchanged).
  • If a class's annotations overlap in time, that track automatically stacks into multiple lanes so they don't cover each other.
  • The ◆ diamond on a spatial track = a keypoint position.
  • The 👁 at the right edge of each gutter row: layered hide (see below); a class track also has a ☑: select all annotations of that class (see "Multi-selection and batch operations").

Layered hide (👁)

Hiding has four levels; the eye buttons in the timeline gutter and in the far-right layers panel mirror each other with the same effect:

  • Whole layer: the 👁 on a group header (PHASE / ACTION / EVENT / TRIPLET / SPATIAL) → hide all annotations of that layer in one click.
  • Whole shape type (spatial only): the 👁 on a shape subgroup (e.g. ▭ bbox) → hide all annotations of that shape.
  • Single class: the 👁 on a class track / class header → hide all annotations of that class.
  • Single annotation: the 👁 on each entry in the layers panel (the original behavior).

Hidden annotations are not drawn on the video and are dimmed on the timeline; this affects display only, the data is untouched. Click the 👁 again (shown as 🚫) to restore.

Multi-selection and batch operations (Shift+left-click / ☑ select-all)

  • Shift+left-click an annotation on the timeline or the video frame = add to / remove from the multi-selection (layers-panel entries can be Shift+clicked too). Multi-selected annotations are marked with a blue dashed frame.
  • ☑ Select all of a class: the ☑ next to the 👁 on the timeline gutter's class track, and on the layers-panel class header— one click adds all annotations of that class to the multi-selection; click again to cancel. It combines with Shift+click to keep adding/removing.
  • When there is a multi-selection, a blue batch-operation bar appears above the timeline: it shows the selected count and offers "🏷 Change class…" (batch-change label, only supported within one layer of selection), "🗑 Batch delete," and "✕ Clear selection."
  • Del: batch-delete the multi-selected annotations (one confirmation).
  • Ctrl+C → Ctrl+V: batch copy. Spatial copies each annotation's shape on the current frame and pastes onto the current frame; temporal uses the earliest start in the selection as the anchor, and on paste the whole group shifts together—the earliest one's start lands on the current frame, the rest keep their relative positions and lengths.
  • An ordinary click (without Shift) on any annotation clears the multi-selection and returns to single selection.

Zoom, pan, navigation

  • Overview strip (the thin strip at the very top): the annotation distribution across the whole video, with an orange box marking the current view window; click or drag it to jump quickly.
  • Plain scroll: scroll the timeline up/down (when there are more tracks than fit the height); Shift+scroll: pan horizontally; Ctrl+scroll: zoom centered on the cursor, all the way down to a frame-by-frame grid.
  • The zoom button at the bottom-right (shows the current level): each click advances one level, 100% → 200% → 400% → 800% → frame level, then back to 100%.
  • At the boundary between the video and the timeline there is a divider (with a short bar in the middle): hold and drag it up/down to adjust the video / timeline height ratio.
  • Clicking a blank spot on a track = jump to that time; hovering shows the time (or frame) at that position.
  • After selecting a segment and pressing E to enter edit mode, you can drag the left/right edges to change start/end (a spatial range cannot shrink inside a keypoint); selecting an annotation makes the video jump to its start in sync.

Layers panel (the far-right "Annotations" area)

  • Lists only the annotations under the current playhead frame (temporal = the start/end covers the current frame; spatial = the frame has a shape), updating live as the playhead moves; the title shows "This frame N."
  • Structure: layer header → (spatial then subdivides into shape-type headers) → class header → individual annotations. The class header shows a color dot + class name + the number in parentheses = that class's total annotation count across the whole video; each entry shows the time range (temporal) or shape + frame range (spatial).
  • 👁: on headers at every level and on individual entries—corresponding to the four-level layered hide above.
  • 🗑: delete that entry.
  • Click an entry: select it and jump to its start (spatial jumps to the first keypoint); Shift+click = add to multi-selection.

9Sampling to generate events

Sometimes you want to place an event marker every fixed number of seconds within "a span" (e.g. sample one point every 30 seconds for quality checking). No need to click them one by one:

  1. Select a temporal segment (any of phase / action / event / triplet).
  2. In the details panel click "Generate events…".
  3. A dialog pops up; choose the interval (every 5 / 10 / 30 / 60 seconds, default 30) and the event class to generate.
  4. The dialog previews "will generate N events" live; confirm and click Generate.

The system generates a 1-frame event annotation every N seconds, starting from the segment's start (inclusive).

If the dropdown has no event class to choose, this project's taxonomy has no event yet → first annotate any span with the ⏱ Segment tool and type to add an event class in the event tab of the class menu (Section 10).

10Label management

The class list (taxonomy) now lives in each project's database (the registry's projects / labels tables), each project independent—no longer editing yaml files.

Method A: add directly in the class menu (use this day-to-day)

  1. Draw a shape or annotate a time segment as usual → the class menu pops up.
  2. Type the new class name in the search box (e.g. clip_applier).
  3. "＋ Add 'clip_applier' to spatial" appears at the bottom of the list → click it or press Enter.
  4. The new class is added to this project's taxonomy immediately and applied to the shape you just drew, and everyone can select it afterward. Spatial classes are auto-assigned a color.

Method B: create a separate project (for a major taxonomy overhaul)

If you need a completely different set of classes (e.g. a different type of surgery), just create a new project on the landing page— the new project has its own clean taxonomy, independent of the old project.

What about the yaml files? pipeline/configs/labels_*.yaml now only serves as the initial seed for the default project and the fallback lists for the triplet three dropdowns (instrument/verb/target); day-to-day class additions/edits are done in the interface, take effect immediately, and require no restart. To adjust the triplet dropdown contents, ask an administrator.
A new class cannot be deleted or renamed from the interface (to avoid invalidating existing annotations). To truly clean up the taxonomy, ask an administrator to handle the database.

12Exporting datasets

Method A: the project page's "📦 Download dataset" (no terminal needed)

The top half is an interactive download form; combine four options freely and download a zip directly:

  1. Format:
    • MOSaiC JSON: one MOSaiC-format JSON per video (temporal + spatial annotations).
    • COCO: spatial annotations converted to COCO (object detection / segmentation).
    • YOLO: spatial annotations converted to YOLO (detection + segmentation txt + data.yaml).
  2. Content: label + images (annotations + corresponding frames) or label only (annotation files only, no images).
  3. Scope: all / spatial only / temporal only / filter spatial by temporal rules—check one or more temporal classes (multi-select = union, e.g. checking two events at once), exporting only the spatial annotations that fall within any checked class's annotation time range. Combined with "sampling to generate events" (Section 9), this yields an evenly sampled spatial dataset.
  4. Class selection: lists all classes in the project taxonomy (all selected by default); just uncheck the ones you don't want.
  5. Click "⬇ Download dataset" → when the export finishes the browser downloads the zip directly (may take a few minutes depending on annotation volume; don't close the page).

The bottom half, "Other exports (original flow)," keeps the original whole-package exports: MOSaiC / COCO / YOLO (no filter applied), temporal (CSV + JSON snapshot), spatial (COCO + extracted frames) —after clicking "Export," statistics appear along with an ⬇ Download run_id.zip link.

The export scope = this project (only this project's videos and annotations). MOSaiC / COCO / YOLO need to extract images and package them, which may take a few minutes depending on annotation volume; don't close the page during export. The CLI can also limit to a project with -P project-code (see Method B).

Method B: the administrator uses the surgann command (conversion to training formats)

Each export creates an independent run directory under data/exports/, containing a complete, reproducible snapshot. Common commands:

CommandOutput
surgann export-dataset -f yolo (or -f mosaic / -f coco) The same three dataset exports as Method A: YOLO detection + segmentation (images/ labels/ labels_seg/ data.yaml + images_meta.csv sidecar) / MOSaiC JSON + images / COCO + images.
surgann export-dataset -f frame-pairs --interval sample_5s temporal → frame–label pairs (sampled frame JPEGs + image_label_pairs.csv).

All time-bearing outputs obey time = frame ÷ fps and self-check after writing, so a time-misaligned dataset is never produced.

13Frequently asked questions

Video not showing up in the project?

A video must first be ingested, and it must be added to this project (Section 2). For an already-ingested video: use "＋ Add video" on the "🎬 Videos" tab or "＋ Add to this project" on "📥 Upload data." For a not-yet-ingested one: go to "📥 Upload data," choose a series, then click "Ingest" (for a patient folder use the "📥 Video ingest" page); if the file is not in the scan table, ask the administrator to place the video into the server's data/raw_videos/ and refresh. An administrator can also ingest it via command:

surgann ingest data/raw_videos/your_video.mp4 --video-id ABCD_0004

Clicked Ingest and nothing happened for a long time?

Transcoding (standardizing to 25fps) takes a few minutes depending on the video's length; the status column shows "⏳ Ingesting…" and updates automatically, and when done the "🎬 Videos" tab gets a new card. If a ✗ error message appears, forward it to the administrator.

Drew a shape but pressed Esc and the annotation disappeared?

Normal—pressing Esc while the class menu is showing means discard this drawing, and the shape is not saved. To keep it you must choose a class.

Too many annotations on the frame, covering each other?

Use 👁 layered hide (Section 8): you can hide a whole layer (e.g. all of spatial), a whole shape type, a single class, or a single annotation in one click— both the timeline gutter and the layers panel have eye buttons. Click back to show them when done. Hiding affects display only; the data is untouched.

A spatial shape looks wrong on another frame?

That's the position linear interpolation filled in between two keypoints. Go to the frame where it's off and drag the shape to the right place—this saves a new keypoint and the interpolation is corrected. If this object shouldn't move continuously (e.g. it only appears for a few instants), turn off "interpolation" in the details panel, and the shape will only show on keypoint frames.

Where are my annotations stored? Could they be lost?

Every action is written to the registry immediately (registry/registry.db), not held temporarily in the browser; switching videos or closing the tab won't lose anything. The administrator periodically makes snapshot backups with surgann backup.

Annotation positions seem to have a time offset?

Check whether the video passed ingest's constant-frame-rate (CFR 25fps) validation—only variable-frame-rate (VFR) videos drift. surgann status should show fps=25.

Added a class by mistake and want to delete it?

The interface does not offer deleting a class (to avoid invalidating existing annotations); ask an administrator to handle it. The annotations themselves can be deleted at any time (🗑 or Del).

Want to change the interface port?

An administrator changes ANNOTATOR_PORT in deploy/.env, or at startup uses surgann annotate --port <number>.

Can I annotate pixel-level masks?

Currently box / polygon / point / ellipse / polyline and ✨ SAM smart assist are available (Section 7); a pixel brush is not. For segmentation, annotate with polygons (SAM generates contour-hugging polygons in one click) — they export as segmentation in COCO.
