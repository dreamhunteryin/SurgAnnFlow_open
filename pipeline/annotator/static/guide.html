SurgAnnFlow Annotator 使用手冊

這是手術影片標註平台的操作說明。你不需要任何前端或伺服器背景，照著每一節一步步做即可。 介面採 Roboflow 式設計：先選工具、先畫形狀，畫完再選類別。 時間軸上的區段標註（temporal）與畫面上的框選標註（spatial）在同一個網頁完成， 影片以專案（project）分庫管理，標完可直接從網頁匯出資料集。

1平台總覽（專案→影片→標註→匯出）

整個平台的使用流程只有四步：

  1. 專案（project）：先建立或選擇一個專案。每個專案有自己的類別清單（taxonomy）與自己的影片。
  2. 影片：把原始影片「入庫（ingest）」到專案——系統會轉成標準化 25fps 影片並登記。
  3. 標註：點影片卡片進入標註頁，用工具畫 temporal 區段與 spatial 形狀。
  4. 匯出：在專案頁「下載資料集」一鍵匯出，或由管理者用 surgann 指令轉成訓練用格式。

標註本身分兩種，同一個介面完成：

  • Temporal（時序）標註：在時間軸上畫「一段時間」。 例如「第 3 分 20 秒到第 5 分是 Calot_triangle_dissection 這個階段」。
  • Spatial（空間）標註：在影片畫面上框出物件。 例如「這一格畫面裡，這個框是 gallbladder（膽囊）」。
名詞小解釋
• 專案（project）：像 Roboflow 一樣，一個專案 = 一個標註任務（例如「膽囊切除 phase 標註」），有自己的影片與類別清單。
• frame（幀）：影片的一格畫面。本平台影片一律轉成固定每秒 25 格，「第幾格」對「第幾秒」是死板的一對一（秒 = frame ÷ 25），標註位置才會精準。
• registry（登錄簿）：一個資料庫檔（registry/registry.db），是平台的單一事實來源。專案、影片、類別、標註全都存在裡面；你在網頁上的每個動作都即時寫入——網頁只是「工作桌」，真正的資料資產在 registry 裡。

2影片庫與專案

由架設者先在終端機啟動服務（surgann annotate），然後你在瀏覽器打開網址（預設）：

http://127.0.0.1:8090

Landing 頁：專案卡

打開網址後看到的是專案列表。每個專案是一張卡片，顯示：專案名稱、類型徽章 （temporal / spatial / mixed）、annotation group（這個專案在標什麼）、影片數。

  • 點專案卡 → 進入該專案的專案頁。
  • 點「＋ 建立專案」 → 彈出建立視窗，填三個欄位： 專案名稱（如 Cholecystectomy Phases）、 類型（temporal＝只標時間軸 / spatial＝只標畫面 / mixed＝兩者皆有，預設 mixed）、 Annotation group（一句話描述在標什麼，如 surgical phases）。 另可選「複製既有專案的類別」——把來源專案的全部類別（含 triplet 三選單）帶進新專案， 只複製類別、絕不複製標註（預設不複製）。按「建立」即完成。

專案頁：四個分頁

專案頁左側有四個分頁（標題列並顯示專案編碼——固定識別碼，匯出與 CLI 以此指定專案）：

分頁內容
🎬 影片 此專案的影片清單。每張卡片：縮圖、影片編號、系列徽章、狀態徽章、長度／解析度／fps、 本專案的標註筆數。點卡片進入標註頁； 右上角另有「＋ 加入影片」與卡片上的「移出專案」（見下方說明）。
📥 上傳資料 單一影片檔的快速入庫：掃描伺服器硬碟 data/raw_videos/ 的結果表（檔名／大小／video_id／狀態）。 檔案先放進該目錄（原始檔唯讀、不會被修改），選好「入庫到系列」後按「入庫」 即轉成標準化 25fps 影片並加入此專案。video_id 由系統依系列自動配號 （{系列ID}_{四位數}，如 ABCD_0004），不需手動命名。 大檔轉檔需數分鐘，狀態會顯示「⏳ 入庫中…」，完成後影片分頁自動出現新卡片。 若檔案已入庫但還不在本專案，會顯示「＋ 加入此專案」按鈕——按一下即可，不用重新轉檔。 病人資料夾（多段錄影需合併＋去識別化）請改用「📥 影片入庫」頁（見下方）。
🏷 類別 此專案的 taxonomy 管理：phase / action / event / spatial 各層的類別清單， 可隨時新增、改名、改色、刪除。改名會同步更新既有標註； 刪除已被使用的類別會先跳確認（連同其標註一併刪除）。 上方另有「從其他專案匯入類別」：把來源專案的類別合併進本專案 （同層同名的自動跳過；不複製標註）。
📦 下載資料集 選匯出格式（MOSaiC / COCO / YOLO / temporal / spatial）→ 按「匯出」→ 完成後出現 ⬇ 下載 zip 連結。 匯出範圍＝本專案。詳見第 12 節。

把影片加入專案（不會複製影片）

影片只需要入庫一次，之後任何專案都可以「引用」它——同一支影片可同時屬於多個專案， 而且每個專案的標註各自獨立（在 A 專案標的東西，B 專案看不到、也不會被影響）。 把影片放進專案有三個入口：

  • ＋ 加入影片（🎬 影片分頁右上）：彈出影片庫清單，列出還不在本專案的已入庫影片 （附系列與時長），逐支按「加入」即可。
  • 📚 整系列匯入（同一個彈窗頂部）：選一個系列（如 ABCD）→ 按鈕 → 該系列所有影片一次全部加入 （已在專案內的自動略過）。
  • 📥 上傳資料：未入庫的檔案按「入庫」（轉檔後自動加入本專案）； 已入庫的按「＋ 加入此專案」。

把影片移出專案

影片卡片右上角（滑鼠移上去出現）的「移出專案」：把影片從本專案清單拿掉， 影片本體仍在影片庫、其他專案完全不受影響。若本專案在這支影片已有標註，會先跳出警告 「此專案在本片有 N 筆標註，移出將一併刪除」——確認後這些標註會被刪除（其他專案的標註不動）， 請務必看清楚筆數再確認。

影片庫與系列（Landing 頁下半部）

Landing 頁專案卡下方是影片庫：所有已入庫影片依系列資料夾分兩層顯示—— 第一層列系列卡（名稱、系列 ID、影片數、機構／術式），點進去才列該系列的影片卡 （無系列的影片歸入「未分類」資料夾；「← 回系列清單」可回上層）。 從影片庫點開影片是純瀏覽模式：只有播放器與影片資訊，不顯示任何標註與標註工具； 頁面右側會列出「所屬專案」，點「✏ 在此專案開啟標註」才進入完整標註模式——標註一律經過專案入口 （同一支影片在不同專案的標註互相獨立）。 系列（series）是影片入庫時的分群單位（資產層，例如同一批來源或同一種術式）， 與標註專案互相獨立：系列管影片資產，專案管標註工作。 系列在「📥 影片入庫」頁建立與管理（名稱／機構／手術類別可隨時改；四碼系列 ID 由系統產生、不可改）， 影片編號依系列自動配號（如 ABCD_0001）。 同系列的影片可在專案頁用「整系列匯入」一次全部加入。

影片入庫頁（病人資料夾批次入庫＋去識別化）

Landing 頁右上「📥 影片入庫」進入。整支手術常被錄影機切成多段檔案放在一個 病人資料夾裡；這一頁把整個資料夾處理成一支去識別化的標準影片，流程五步：

  1. 選系列（或先在頁面上方建立新系列），可順帶選「完成後加入某標註專案」。
  2. 提供病人資料夾，兩個入口擇一： 伺服器磁碟選取（管理者把資料夾放進 data/raw_videos/_incoming/ 後按重新掃描） 或 瀏覽器上傳（直接選取本機資料夾，切成 50MB 區塊上傳，斷線可續傳）。
  3. 確認合併順序：系統依檔名排序列出所有檔案，可拖曳調整順序後排入處理佇列 （順序錯了合併結果無法回復，請比對錄影段落先後；若出現「⚠ mtime 不一致」警告要特別檢查）。
  4. 系統自動：合併 → 偵測體外（out-of-body）畫面 → 停在 「待 QC 核可」——請點「🔍 QC 核可」檢視建議切除段的縮圖， 可微調起訖秒數、刪除誤判段或新增漏抓段，核可後才會切除並轉檔。 每段旁的信心徽章：● 高信心（綠，體外機率中位數 ≥ 0.9）大多可信； ▲ 存疑（黃，< 0.9）＝模型不太確定，請優先檢查這些段的縮圖是否誤判。 誤留體外畫面＝隱私事故，寧可多切。
  5. 完成後影片自動入庫（依系列配號）、加入所選專案；原始資料夾移到 archived/ 保存（不刪除），頁面下方顯示可清理空間供管理者參考。
第一次使用前：同意 OOB 模型授權。去識別化用的體外偵測（OOB）模型已隨程式附帶，但授權為 CC BY-NC-SA 4.0（僅限非商業研究），必須由管理者先閱讀並同意：在伺服器終端機執行 surgann fetch-models --only oob，完成後重新整理本頁。尚未同意時頁面頂部會顯示提示橫幅， 且「排入處理佇列」會被擋下（否則 job 會在去識別化階段失敗）；系列管理與瀏覽器上傳不受影響。

處理佇列一次跑一夾，伺服器重啟會自動續跑；失敗的 job 可「重試」或「刪除」（刪除時可選擇連同暫存檔一併清掉）。

影片沒出現在專案裡？ 先確認影片已入庫，再用上面任一入口把它加入本專案。 若「📥 上傳資料」的掃描表裡沒有該檔案，請先請管理者把影片放到伺服器的 data/raw_videos/（見第 13 節）。
建議先把影片從頭到尾看過一遍再開始標，對整體流程有概念後效率更高。

3進入標註頁

  1. Landing 頁 → 點專案卡。
  2. 專案頁「🎬 影片」→ 點影片卡片（等同開啟 app.html?v=ABCD_0001）。
  3. 標註頁載入後，可用的類別清單就是這個專案的 taxonomy（每個專案各自獨立）。

在標註頁的頂欄：

  • 📁 影片庫：回到專案頁換影片／換專案。
  • ☰ 選單：內含「📖 使用手冊（新分頁，就是本頁）」與「⌨ 快捷鍵清單」。
  • 中間顯示目前影片編號與專案徽章（標註只記在這個專案底下）。
  • 右側是標註者選擇器（見下方）。

選擇標註者（開工前先確認！）

頂欄右側的「標註者」下拉選單決定接下來的每一筆標註記在誰名下。 開始標之前先確認選的是自己：

  1. 點開下拉選單，選自己的名字。
  2. 名單裡沒有你？選「＋ 新增標註者…」→ 輸入名字（如：王醫師）→ 確定，系統會把你加進名冊並自動選取。
  3. 選一次就會被瀏覽器記住，下次打開自動帶入；中途換人標，記得先換這裡。
同一支影片、同一個專案可以有多位標註者的標註並存；匯出時每筆標註都帶著標註者資訊，之後可以分開統計或比對。

5核心工作流：先畫，後選類別

SurgAnnFlow 採 Roboflow 式流程——不用先想好類別，先把東西畫出來，畫完系統才問你「這是什麼」：

  1. 選工具：右側工具列點一下，或按快捷鍵（B 框、T 時段…）。
  2. 畫：在影片上畫形狀（spatial）；temporal 則是按 T 記下起點、播放/點時間軸延伸、Enter 設終點（第 6 節）。
  3. 選類別：畫完，畫面上自動彈出浮動類別選單（class popup）， 列出這個專案的類別（如 gallbladder、hook…）。點一個，或打字搜尋後按 Enter。
  4. 完成：標註立即存進 registry（右下角出現「已標註 ×××」提示），並自動選取這筆。

浮動類別選單的操作

  • 搜尋框：直接打字過濾；↑/↓ 移動、Enter 選定。
  • 新增類別：打一個不存在的名稱，清單底部會出現「＋ 新增『×××』」，點它（或 Enter） 即把新類別加進這個專案的 taxonomy 並直接套用（見第 10 節）。
  • 上次用的類別會標 ↩ 記號且預設反白——直接按 Enter 即套用，方便連續標同一種東西。
  • temporal 的選單有分頁：phase / action / event / triplet 四個 tab，先切層再選類別（見第 6 節）。
  • Esc：放棄這次繪製（形狀不會存）。

N：自動套用上次類別（連續標同物件的加速器）

按 N 開啟後，每畫完一個形狀就直接套用上一次的 spatial 類別，不再跳類別選單—— 適合一口氣標幾十個同種物件。再按一次 N 關閉。

  • 需要先手動標過一個 spatial（有「上次類別」可套用）。
  • 開啟時若目前不是繪製工具，會自動切到 ▭ 框。
典型節奏：B 選框工具 → 畫第一個 → 選 hook → 按 N → 之後每畫一個框都自動是 hook → 標完按 N 關閉。

6Temporal 標註（時間區段）

Temporal 標註是在時間軸上畫「一段」。共有四層，彼此完全獨立、可同時重疊：

層意義範例
phase手術階段Preparation、Calot_triangle_dissection…
action動作 / 動詞grasp、dissect、clip…
event點狀或短區段事件bleeding、CVS_achieved…
triplet一段區間掛上（器械, 動作, 目標）三元組grasper + dissect + cystic_duct

標一段 temporal（邊看邊標）

  1. 先對好起點：暫停影片，或點時間軸跳到目標 frame。
  2. 按 T 或點工具列的 ⏱ 時段＝開始標註，起點就是目前 frame。 時間軸上方出現橘色「⏺ 時段標註中」列，顯示目前的起訖與長度。
  3. 延伸這段的長度，兩種方式可混用：
    • 播放影片（Space）——播放頭走到哪，這段就跟到哪；
    • 點時間軸某處——這段自動縮放到該時間點（點在起點之前＝把起點往前拉）。
  4. 按 Enter 或橘色列上的「✓ 確認」＝設定終點，彈出類別選單 （phase / action / event / triplet 四個分頁），且預設反白上一次使用的類別。
  5. 再按一次 Enter＝直接以預設類別完成； 要換類別就點清單（或打字搜尋 + Enter）。
  • 「時段」是單次性的：每完成一個標註，⏱ 鈕自動回到非啟用狀態； 非標註中點時間軸只是跳時間，絕不會產生標註。
  • 標註中再按一次 T（或 ⏱ 鈕）＝取消這段；Esc 亦可（確認前隨時可按）。
  • 分頁會記住你上一次用的層，連續標同一層不用重切。
連續標同一類別的節奏：對好起點 → T → 播放到終點 → Enter → Enter——兩下 Enter 就是一筆。

triplet 三選單

在類別選單的 triplet 分頁選定後，選取詳情面板會出現 instrument / verb / target 三個下拉選單， 三個都選好即完成一個手術動作三元組。

微調與刪除

  • 雙擊區段＝開編輯彈窗：可直接改類別與起訖 frame， 改起訖時影片會同步跳到該 frame。
  • 拖邊緣（要先進編輯模式）：選取區段後按 E 進入編輯模式， 才能拖區段的左右邊緣——未進編輯模式時純瀏覽、不會誤拖。拖的時候影片畫面會跟著跳， 看畫面就知道拉到哪一秒 / 哪一 frame。再按 E 或改選其他標註即離開編輯模式。
  • 極短的區段（如 1 frame）也拖得到：編輯模式下點它的左半邊拉起點、右半邊拉終點。
  • 在時間軸上點選任一標註，影片會同步跳到該標註的起點。
  • 詳情面板的 Start / End 欄位可直接輸入 frame；旁邊的 ⌖ = 設為目前 frame。
  • 刪除：選取後按 Del、編輯彈窗的「刪除」，或 layers 面板的 🗑。
「事件只有一瞬間」也沒問題——停在該 frame 按 T 後直接 Enter 即是 1-frame 標註； 需要規律的點狀 event 可用「抽樣生成 event」（第 9 節）。

7Spatial 標註（畫面框選）

Spatial 標註是在影片畫面上畫形狀框住物件。五種手畫工具＋一個 AI 輔助工具：

工具鍵畫法
▭ 框（bbox）B按住拖曳出對角。
⬠ 多邊形（polygon）P逐點點擊，Enter 或雙擊收尾（至少 3 點）。
• 點（point）O點一下即完成。
⬭ 橢圓（ellipse）E按住拖曳出外接框。
〰 折線（polyline）L逐點點擊，Enter 或雙擊收尾（至少 2 點）。
✨ 智慧（smart，SAM 輔助）S點物件＝正點、按住拖曳＝框提示； AI 即時生成 polygon 預覽（藍色虛線虛影＋信心分數）。修正很直覺：點在預覽虛影「內」＝自動變負點 （把點擊處從形狀扣掉，紅點）、點在虛影「外」＝正點（綠點）——通常不需要按 Alt； Alt+點＝強制負點（不論點在哪）。可連續加點/重畫框修正，Ctrl+Z 逐步撤銷上一個點/框； Enter 或浮條的「✓ 確認」鈕＝接受 → 選類別落地為一般 polygon， Esc／換 frame／換工具＝清除重來。
✨ 智慧工具備註
• 需要後端 SAM 模型服務就緒，未就緒時會提示「SAM 模型未就緒」（其他工具不受影響）。
• 首次在某 frame 點擊需短暫等待（GPU 約 0.5 秒內；無 GPU 需數秒）， 同 frame 後續修正幾乎即時。
• polygon 頂點上限 150：即使滑桿拉到最精細，超過時系統自動加大簡化強度收斂到 150 以內 （頂點太多會讓之後的逐點編輯很痛苦）。
• 精細度滑桿（畫布左下浮條，smart 工具下出現）：控制 polygon 頂點多寡——越「精細」頂點越多越貼合、 越「簡略」頂點越少越好編輯；旁邊即時顯示目前預覽的頂點數。預設「自動」（系統調到適中頂點數）； 一拖滑桿即改為手動值（會記住，下次沿用），按「自動」鈕可隨時切回。拖動只改簡化程度，已點的正/負點與框都保留。
• 落地後就是一般的 polygon 標註（單 frame、插值關閉）：可照常編輯頂點、複製、刪除、匯出。

畫完 → 彈出類別選單 → 選類別 → 存檔（第 5 節的流程）。繪製中會顯示十字準星輔助對位；Esc 取消繪製。

點擊超出影像範圍也沒關係——系統會自動取影像邊界上最接近滑鼠的點作為頂點 （座標貼齊邊界），畫貼邊的 bbox / polygon 不必瞄得剛剛好。

keypoint + 線性插值（讓一個框跨多個 frame 移動）

Spatial 標註有時間跨度（start/end frame）。你不用每一格都畫，只要在關鍵 frame 調整形狀， 中間的位置系統會自動內插補上。

  1. 畫好形狀（第一個 keypoint 落在目前 frame）。
  2. 用 ⬚ 選取工具選住它、按 E（或左鍵快速連點兩下該標註）進入編輯模式，播放或跳到後面某個 frame。
  3. 拖動形狀本體或某個白色頂點把手——這會在目前 frame 存一個新的 keypoint （標註的時間範圍會自動延伸涵蓋這個 frame）。
  4. 兩個 keypoint 之間的每一格，形狀位置會線性內插自動算出來。
插值規則（詳情面板可切「插值」開關）
• 開啟插值：前後 keypoint 之間、且頂點數相同 → 逐座標線性內插；頂點數不同（多邊形有增減點）→ 沿用前一個 keypoint（hold）；超出兩端 → 取最近端點的形狀。
• 關閉插值：只在有 keypoint 的 frame 才顯示形狀。

選取 spatial 標註後，詳情面板列出所有 keypoint（◆ f123）：點它跳到該 frame、✕ 刪除該 keypoint（至少保留一個）。 transport 的 ◆◀ / ▶◆ 可跳上一／下一個 keypoint；時間軸的 spatial 軌道上也用 ◆ 菱形標出 keypoint 位置。

編輯形狀與頂點（選取後按 E，或左鍵連點兩下標註，進入編輯模式）

  • 先選取、再按 E：未進編輯模式時純瀏覽（點形狀只是選取，不會誤拖）； 進入後白色頂點把手才出現、才可拖拉。再按 E／按 Esc／改選其他標註即離開。
  • 移動：拖形狀本體——碰到影像邊界就停在邊界，整體移動不會移出畫面。 改形：拖白色頂點把手（bbox 四角、橢圓四軸端、多邊形/折線每個頂點）； 單一頂點拖出影像時仍照舊貼齊邊界最近點。每次拖動＝在目前 frame 存 keypoint。
  • Ctrl+點擊（polygon / polyline，編輯模式中）：點在邊上插入一個頂點；點在既有頂點上刪除該頂點。
  • Alt+左鍵拖曳（polygon，編輯模式中）：沿滑鼠軌跡重繪一段邊緣—— 從邊緣附近按住 Alt 拖出想要的新輪廓（粉紅預覽線），放開即把「離軌跡較近的那段舊邊緣」換成你畫的軌跡。 軌跡太短或起訖離邊緣太遠（>40px）會提示並不套用。
  • 快速進入編輯模式：選取工具下，在標註上滑鼠左鍵快速連點兩下＝選取並直接進入編輯模式（等同按 E）。
  • 編輯完照常 Ctrl+Z 可復原（含 Alt+拖曳重繪）。

複製 / 貼上形狀

  • Ctrl+C：複製目前選取的形狀（以目前 frame 顯示的位置為準）。
  • Ctrl+Shift+C：複製目前 frame 上所有可見的形狀。
  • Ctrl+V：貼到目前 frame（類別與位置保留，成為新的獨立標註）。
  • 多選（Shift+左鍵）後的批次複製見第 8 節「多選與批次操作」。

影片縮放（標小物件用）

  • Ctrl+滾輪：以游標為中心縮放影片（最大 10 倍）。
  • 滾輪 = 垂直捲動、Shift+滾輪 = 水平捲動——只在放大（>100%）時有效， 100% 時滾輪不會移動畫面；捲動也不會超出影像邊緣。
  • 放大（>100%）時，畫面下緣／右緣會出現細細的捲動 bar： 拖曳 thumb 或點軌道即可左右／上下平移畫面（範圍同樣不會超出影像邊緣）；≤100% 時自動隱藏。
  • 在影片區雙擊還原縮放（繪製或選取中時不會誤觸還原）。
目前的 spatial 工具範圍：框／多邊形／點／橢圓／折線，加上內建的 ✨ SAM 智慧輔助（見本節上方）， 涵蓋日常標註所需。像素筆刷 mask 尚未提供——需要逐像素 segmentation 時， 先用多邊形（或 SAM 產生的多邊形）標，匯出 COCO 時可轉為 mask。

8時間軸與 layers 面板

時間軸（MOSaiC 式分軌，三層樹狀）

底部時間軸的左側 gutter 是三層樹狀結構：

  • 第一層：TEMPORAL / SPATIAL 兩個總群組。
  • 第二層：TEMPORAL 下依層分組（PHASE / ACTION / EVENT / TRIPLET）； SPATIAL 下依形狀種類分組（▭ bbox、⬠ polygon、• point、⬭ ellipse、〰 polyline）。
  • 第三層：每個已被標註的類別各自一軌——不同類別絕不混在同一列。
  • ▸/▾ 收合：前兩層標頭左緣有收起/展開鈕（點標頭列的左半也可）——收起只是摺疊底下的軌道讓畫面變短， 不是隱藏標註（影片上與 layers 面板照常顯示；👁 眼睛鈕行為不變）。
  • 同一類別的標註若時間重疊，該軌會自動堆疊成多條 lane，不互相蓋住。
  • spatial 軌道上的 ◆ 菱形 = keypoint 位置。
  • gutter 每列右緣的 👁：分層隱藏（見下）；類別軌另有 ☑：全選該類別的所有標註（見「多選與批次操作」）。

分層隱藏（👁）

隱藏有四個層級，時間軸 gutter 與最右 layers 面板的眼睛鈕互相呼應、效果相同：

  • 整層：群組標頭（PHASE / ACTION / EVENT / TRIPLET / SPATIAL）的 👁 → 一鍵隱藏該層全部標註。
  • 整個形狀種類（spatial 專用）：形狀子群組（如 ▭ bbox）的 👁 → 隱藏該形狀的全部標註。
  • 單一類別：類別軌／類別標頭的 👁 → 隱藏該類別的全部標註。
  • 單一標註：layers 面板每筆的 👁（原有行為）。

隱藏的標註不畫在影片上、時間軸上變淡；只影響顯示，資料不動。再點一次 👁（顯示為 🚫）即恢復。

多選與批次操作（Shift+左鍵 / ☑ 全選）

  • 在時間軸或影片畫面上 Shift+左鍵點標註＝加入／移出多選 （layers 面板的項目也可 Shift+點）。多選中的標註以藍色虛線框標示。
  • ☑ 全選類別：時間軸 gutter 類別軌的 👁 旁、以及 layers 面板類別標頭的 ☑—— 一鍵把該類別的所有標註加入多選；再按一次取消。可搭配 Shift+點繼續加減選。
  • 有多選時，時間軸上方會出現藍色批次操作列：顯示已選數量， 提供「🏷 改類別…」（批次改 label，僅支援同一層的選取）、「🗑 批次刪除」與「✕ 清除選取」。
  • Del：批次刪除多選的標註（跳一次確認）。
  • Ctrl+C → Ctrl+V：批次複製。spatial 複製各標註在目前 frame 的形狀、貼到目前 frame； temporal 以選取中最早的起點為基準，貼上時整組平移——最早那筆的起點落在目前 frame，其餘保持相對位置與長度。
  • 一般（不按 Shift）點選任何標註會清空多選、回到單選。

縮放、平移、導航

  • 概覽條（最上方細條）：整支影片的標註分佈，橘框是目前檢視窗；點或拖它快速跳位。
  • 一般滾輪：時間軸上下捲動（軌道多到超出高度時）； Shift+滾輪：水平平移；Ctrl+滾輪：以游標為中心縮放， 一路可放大到一格一格的 frame 網格。
  • 右下角縮放鈕（顯示目前級別）：每按一下跳一級，100% → 200% → 400% → 800% → frame 級，再按回到 100%。
  • 影片與時間軸交界處有一條分隔線（中間有短橫桿）：按住上下拖曳，調整影片 / 時間軸的高度比例。
  • 點軌道空白處 = 跳到該時間；游標懸停會顯示該位置的時間（或 frame）。
  • 選取區段並按 E 進入編輯模式後，可拖左右邊緣改起訖（spatial 的範圍不能縮進 keypoint 之內）； 點選標註時影片會同步跳到其起點。

layers 面板（最右「標註」區）

  • 只列目前播放頭 frame 底下的標註（temporal＝起訖涵蓋目前 frame；spatial＝該 frame 有形狀）， 播放頭移動時即時更新；標題顯示「本 frame N」。
  • 結構：層標頭 →（spatial 再分形狀種類標頭）→ 類別標頭 → 各筆標註。 類別標頭顯示顏色點＋類別名＋括號數字＝該類別在整支影片的標註總數； 各筆顯示時間範圍（temporal）或形狀＋frame 範圍（spatial）。
  • 👁：各層級標頭與單筆都有——對應上述四級分層隱藏。
  • 🗑：刪除該筆。
  • 點某筆：選取並跳到它的起點（spatial 跳到第一個 keypoint）；Shift+點＝加入多選。

選取詳情面板

欄位 / 按鈕作用
Start / End ＋ ⌖直接輸入起訖 frame；⌖ = 設為目前 frame。
instrument / verb / targettriplet 專用三選單。
插值開關 ＋ keypoints 清單spatial 專用：切換線性插值；每個 ◆ f123 可點跳、✕ 刪除。
抽樣「生成 event…」temporal 專用，見第 9 節。

9抽樣生成 event

有時你想在「某一段」裡每隔固定秒數放一個 event 標記（例如每 30 秒抽一個點做品質檢查）。不用手動一個個點：

  1. 選取一段 temporal 區段（phase / action / event / triplet 皆可）。
  2. 在詳情面板點 「生成 event…」。
  3. 彈出視窗選間隔（每 5 / 10 / 30 / 60 秒，預設 30）與要生成的 event 類別。
  4. 視窗會即時預告「將生成 N 個 event」，確認後按生成。

系統會從這段的起點（含）開始，每 N 秒生成一個 1-frame 的 event 標註。

若下拉沒有可選的 event 類別，代表這個專案的 taxonomy 還沒有 event → 先隨便用 ⏱ 時段工具標一段、在類別選單的 event 分頁打字新增一個 event 類別（第 10 節）。

10標籤（label）管理

類別清單（taxonomy）現在存在每個專案的資料庫裡（registry 的 projects / labels 表）， 每個專案各自獨立——不再是改 yaml 檔。

方式 A：在類別選單裡直接新增（日常用這個）

  1. 照常畫一個形狀或標一段時段 → 彈出類別選單。
  2. 在搜尋框打新類別的名字（如 clip_applier）。
  3. 清單底部出現「＋ 新增『clip_applier』到 spatial」→ 點它或按 Enter。
  4. 新類別立即加入這個專案的 taxonomy 並套用到剛畫的標註，之後所有人都選得到。spatial 類別會自動配色。

方式 B：另建專案（taxonomy 大改時）

若要一套完全不同的類別（例如換一種手術），直接在 landing 頁建立新專案—— 新專案有自己乾淨的 taxonomy，與舊專案互不影響。

那 yaml 檔呢？ pipeline/configs/labels_*.yaml 現在只作為 default 專案的初始種子與 triplet 三選單（instrument/verb/target）的後援清單， 日常增修類別都在介面內完成、即時生效、不必重啟。triplet 的三選單內容要調整時請找管理者。
新增類別無法從介面刪除或改名（避免既有標註失效）。真的要整理 taxonomy 請找管理者處理資料庫。

11完整快捷鍵表

與介面「☰ 選單 → ⌨ 快捷鍵清單」完全一致：

12匯出資料集

方式 A：專案頁「📦 下載資料集」（不用開終端機）

上半部是互動式下載表單，四個選項自由組合後直接下載 zip：

  1. 格式：
    • MOSaiC JSON：每支影片一份 MOSaiC 格式 JSON（temporal＋spatial 標註）。
    • COCO：spatial 標註轉 COCO（物件偵測/分割）。
    • YOLO：spatial 標註轉 YOLO（偵測＋分割 txt＋data.yaml）。
  2. 內容：label + images（標註＋對應影像）或 label only（只要標註檔，不含影像）。
  3. 範圍：全部 / 只要 spatial / 只要 temporal / 以 temporal 規則篩選 spatial——勾選一個或多個 temporal 類別（可複選＝聯集， 如同時勾兩個 event），只匯出落在任一勾選類別標註時間範圍內的 spatial 標註。 搭配「抽樣生成 event」（第 9 節）即可取得等間隔抽樣的 spatial 資料集。
  4. 類別勾選：列出專案 taxonomy 全部類別（預設全選），把不要的取消勾選即可。
  5. 按「⬇ 下載資料集」→ 匯出完成後瀏覽器直接下載 zip（依標註量可能需數分鐘，請勿關閉頁面）。

下半部「其他匯出（原有流程）」保留原本的整包匯出： MOSaiC / COCO / YOLO（不套用篩選）、temporal（CSV＋JSON 快照）、spatial（COCO＋抽幀影像） ——按「匯出」後顯示統計並出現 ⬇ 下載 run_id.zip 連結。

匯出範圍＝本專案（只含此專案的影片與標註）。 MOSaiC / COCO / YOLO 需抽取影像並打包， 依標註量可能要數分鐘，匯出中請勿關閉頁面。CLI 亦可用 -P 專案編碼 限定專案（見方式 B）。

方式 B：管理者用 surgann 指令（訓練用格式轉換）

每次匯出會在 data/exports/ 建一個獨立 run 目錄，含完整快照、可重現。常用：

指令產出
surgann export-dataset -f yolo（或 -f mosaic / -f coco） 同方式 A 的三種資料集匯出：YOLO 偵測＋分割（images/ labels/ labels_seg/ data.yaml＋images_meta.csv sidecar） / MOSaiC JSON＋影像 / COCO＋影像。
surgann export-dataset -f frame-pairs --interval sample_5s temporal → 影格–label 配對（抽樣 frame JPEG＋image_label_pairs.csv）。
surgann export-dataset -f clip --cut temporal → clip–label 配對（clip_label_pairs.csv；--cut 加切出 clips/*.mp4）。
surgann export-temporal / export-spatial 與方式 A 相同的兩種匯出（CSV＋JSON 快照 / COCO＋抽幀影像）。
-P 專案編碼（如 surgann export-dataset -f yolo -P default） export-dataset / export-temporal / export-spatial 皆可加， 匯出限定該專案；省略＝全 registry。
surgann derive 由連續區段推導每 5s / 30s 抽樣點的 frame-level label CSV。
surgann export-mosaic --video ABCD_0001 / import-mosaic 與 MOSaiC 平台 JSON 格式互轉（座標百分比↔像素自動換算，可 round-trip）。

所有含時間的輸出都遵守 time = frame ÷ fps 並在寫檔後自檢，不會產出時間錯位的資料集。

13常見問題

影片沒出現在專案裡？

影片必須先入庫，而且要加入本專案（第 2 節）。已入庫的影片： 用「🎬 影片」分頁的「＋ 加入影片」或「📥 上傳資料」的「＋ 加入此專案」。 還沒入庫的：到「📥 上傳資料」選好系列後按「入庫」（病人資料夾請走「📥 影片入庫」頁）；若掃描表裡沒有該檔案， 請管理者把影片放到伺服器的 data/raw_videos/ 再重新整理。也可由管理者用指令入庫：

surgann ingest data/raw_videos/你的影片.mp4 --video-id ABCD_0004

入庫按了很久沒反應？

轉檔（標準化成 25fps）依影片長度需要數分鐘，狀態欄會顯示「⏳ 入庫中…」並自動更新；完成後「🎬 影片」分頁會多出新卡片。若顯示 ✗ 錯誤訊息，把訊息轉給管理者。

畫完形狀但按了 Esc，標註不見了？

正常——類別選單出現時按 Esc 表示放棄這次繪製，形狀不會存。要保留就得選一個類別。

畫面上的標註太多、互相蓋住？

用 👁 分層隱藏（第 8 節）：可一鍵隱藏整層（如整個 spatial）、整個形狀種類、單一類別，或單筆標註—— 時間軸 gutter 與 layers 面板都有眼睛鈕。標完再點回來顯示。隱藏只影響顯示，資料不動。

spatial 形狀在別的 frame 位置怪怪的？

那是線性插值在兩個 keypoint 之間補出來的位置。到位置不對的 frame 把形狀拖正——這會存一個新 keypoint，插值即被修正。 若這個物件不該連續移動（例如只出現幾個瞬間），把詳情面板的「插值」關掉，形狀就只在 keypoint frame 顯示。

我的標註存在哪裡？會不會不見？

每個動作都即時寫進 registry（registry/registry.db），不是暫存在瀏覽器；換影片、關分頁都不會遺失。 管理者會定期用 surgann backup 做快照備份。

標註位置好像有時間偏移？

檢查該影片是否通過 ingest 的固定幀率（CFR 25fps）驗證——只有可變幀率（VFR）的影片才會漂移。 surgann status 應顯示 fps=25。

新增錯了類別想刪掉？

介面不提供刪除類別（避免既有標註失效），請找管理者處理。標註本身可隨時刪（🗑 或 Del）。

想換介面的 port？

管理者改 deploy/.env 的 ANNOTATOR_PORT，或啟動時 surgann annotate --port <數字>。

可以標像素級的 mask 嗎？

目前提供框／多邊形／點／橢圓／折線與 ✨ SAM 智慧輔助（第 7 節），尚未提供像素筆刷。 需要 segmentation 時用多邊形標（SAM 可一鍵產生貼合輪廓的多邊形），匯出 COCO 時即為分割標註。
