影片

此專案還沒有影片 — 按「＋ 加入影片」從影片庫挑選已入庫的影片， 或到「📥 上傳資料」把硬碟上的原始影片入庫到這個專案。

上傳資料（掃描後端硬碟）

單一影片檔快速入庫：檔案先放到伺服器的 data/raw_videos/（原始檔唯讀、不會被修改）， 選擇系列後按「入庫」——會轉成標準化 25fps 影片、依系列自動配號（如 ABCD_0004）並加入此專案（大檔需數分鐘）。
病人資料夾（多段錄影合併＋體外畫面去識別化）請改用 📥 影片入庫 頁的處理佇列。

類別（taxonomy）

每個專案有獨立的類別清單，隨時可增改。改名會同步更新此專案內既有標註； 刪除已被使用的類別會先跳出確認，確認後連同其標註一併刪除。

下載資料集

自訂內容 / 範圍 / 類別後直接下載 zip。匯出範圍＝本專案（編碼 ）。 影格配對 / clip 配對請用 CLI：surgann export-dataset -f frame-pairs -P 。
只匯出落在勾選之 temporal label 標註時間範圍內的 spatial 標註（可複選＝聯集）：

其他匯出（原有流程）

MOSaiC / COCO / YOLO＝資料集匯出（標註＋對應影像，不套用上方篩選）； temporal＝時間軸標註 CSV＋JSON 快照、spatial＝空間標註 COCO＋抽幀影像。

加入影片到此專案

列出影片庫中還不在本專案的已入庫影片。加入只是把影片放進本專案清單 （同一支影片可同時屬於多個專案，各專案的標註互相獨立）。
